# Publication readiness

Version 0.1.0 includes package metadata, MIT license, an offline synthetic example,
tests, CI configuration and source provenance. The public repository is
https://github.com/zackgti/universal-distiller. It is not published to PyPI,
and no sponsor application has been submitted for this project.

Release checks:

- Review the retained prototype code's ownership and the chosen MIT license.
- Run tests and installation in a clean environment; inspect the source archive.
- Create the repository under the maintainer's account and push the code.
- Let the configured Windows/Linux CI run and record its actual results.
- Publish a short usage example and invite real feedback. Record maintenance as it
  occurs; do not backdate commits, fabricate users, stars, downloads or issues.

Sponsor readiness comes later: demonstrable use, real issue/PR work, releases and
ecosystem value. A new repository alone does not establish eligibility.
