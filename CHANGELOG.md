# Changelog

## 0.1.0 — first experimental release

- Collect explicit HTTP(S) pages and UTF-8 local text with content-addressed archives.
- Preserve source identity, publication/collection dates and content hashes.
- Validate source references, exact quotations, archive integrity and support rules.
- Retain opposing evidence in both offline HTML and Markdown reports.
- Record failed collection attempts and report research gaps.
- Snapshot research data and compare subsequent changes.
- Include an offline synthetic demo, bilingual README and Windows/Linux CI configuration.

No built-in search or model provider; synthesis and source-quality assessment
remain researcher responsibilities. The first release does not imply external
adoption, independently verified facts, or sponsorship eligibility.
